# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately:

1. **Do NOT** open a public GitHub issue.
2. Email details to: `security@portfolio.local` (or contact Alef Salu directly).
3. Include the following information:
   - Type of issue (e.g. buffer overflow, SQL injection, privilege escalation).
   - Full steps to reproduce the vulnerability.
   - Proof-of-concept exploit code if available.
   - Any suggested mitigations.

You will receive an acknowledgment within 48 hours and regular updates on the remediation progress.
